# VibeCheck documentation starter

This package contains documentation only. It does not scaffold or implement the application.

## Installation

Extract the ZIP into the **root of your existing VibeCheck Git repository**, so `AGENTS.md` sits alongside the `docs` directory. Do not extract into an extra nested `VibeCheck-docs` folder.

The `docs/MASTER_SPEC.md` file preserves the supplied Claude document. Supporting files contain relevant sections extracted from it, with no new architecture decisions.

**Missing source:** the separate feature-level plan `docs/plan/vibecheck.md` was referenced but not supplied. Its placeholder calls out this gap; do not treat it as a finished plan.
